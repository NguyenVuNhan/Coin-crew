# Web split (web / zalo / web-common) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move everything shared out of `apps/web` into a new `packages/web-common` package, leaving `apps/web` as a thin browser shell, with no behaviour change.

**Architecture:** `@fsl/web-common` holds the React app (screens, components, lib, i18n, api client, styles, tests) and exports an `AppRoot` that wraps the providers `main.tsx` sets up today. `apps/web` keeps `main.tsx`, `index.html`, `public/` and the Vite/PWA config and renders `AppRoot`. `apps/zalo` is **not** created here; the Zalo plan adds it. Every project is Nx-adoptable later: own `package.json` scripts, own `tsconfig`, no cross-project relative imports.

**Tech Stack:** npm workspaces, Vite 8 (rolldown), React 19, Tailwind v4 (`@tailwindcss/vite`), Vitest 4 + jsdom, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-01-zalo-mini-app-design.md` §1 ("Split the web app into web, zalo and common").

## Global Constraints

- Pure move: no behaviour, copy, class name (`fsl-*`), `data-testid` or route changes.
- Use `git mv` so history follows the files.
- Package name `@fsl/web-common`, folder `packages/web-common`.
- `apps/web` still builds into `apps/api/public`; root scripts `dev`, `e2e`, `tunnel` keep calling `@fsl/web`.
- Theme stays only in `globals.css` (now `packages/web-common/src/styles/globals.css`); the style guard keeps enforcing "one stylesheet, no raw hex".
- shadcn: `components.json` moves to `packages/web-common`; `.mcp.json` and `CLAUDE.md` point there.
- No project imports another project's files by relative path; `apps/web` imports only `@fsl/web-common` (and `@fsl/web-common/styles.css`).

## Review Focus

1. Tailwind class detection: classes used only in `packages/web-common` must still be generated in the `apps/web` build (Tailwind v4 auto-detects from the Vite root, which is now `apps/web`). Expected: identical CSS; pinned by Task 1 Step 6 (`@source`) and the built-CSS check in Task 1 Step 8.
2. PWA/service worker: the built `apps/api/public` still contains `sw.js`, `manifest.webmanifest` and the `og/`, `brand/` assets. Pinned in Task 1 Step 8.
3. Tests that read files by path (`style-guard.test.ts`, `ui-components-guard.test.ts`, `theme.test.ts`) must still find the real files after the move, not pass vacuously on an empty list. Pinned in Task 1 Step 4 (assert non-empty file lists).
4. The `@/` alias: shadcn components import `@/lib/utils`; it must resolve to `packages/web-common/src` both in Vitest and when `apps/web` builds. Pinned by Task 1 Step 7 (`build` + `typecheck`).
5. The e2e golden path (real Worker + built assets on 375px) still passes. Task 2 Step 3.

### Task 1: Create `@fsl/web-common` and make `apps/web` a shell

**Files:**
- Create: `packages/web-common/package.json`, `packages/web-common/tsconfig.json`, `packages/web-common/vitest.config.ts`, `packages/web-common/src/index.ts`, `packages/web-common/src/AppRoot.tsx`
- Move (`git mv`): `apps/web/src/{App.tsx,components,config.ts,i18n,lib,screens,styles,test,api}` → `packages/web-common/src/`; `apps/web/components.json` → `packages/web-common/components.json`
- Modify: `apps/web/src/main.tsx`, `apps/web/package.json`, `apps/web/tsconfig.json`, `apps/web/vite.config.ts`, `packages/web-common/src/test/style-guard.test.ts`, `packages/web-common/src/styles/globals.css`, `package-lock.json` (via `npm install`)

**Interfaces:**
- Produces: `@fsl/web-common` exports `AppRoot(): JSX.Element` (QueryClientProvider with today's `QueryClient` options + `BrowserRouter` + `NavHistoryProvider` + `App`), `bootApp(): void` (today's `setLang(detectLang())` + `refetchOnWindowFocus()`), and the sub-path `@fsl/web-common/styles.css` → `src/styles/globals.css`. The Zalo plan extends `AppRoot` with a `platform` prop.

- [ ] **Step 1: Move the files**

```bash
mkdir -p packages/web-common/src
git mv apps/web/src/App.tsx apps/web/src/config.ts packages/web-common/src/
for d in api components i18n lib screens styles test; do git mv apps/web/src/$d packages/web-common/src/$d; done
git mv apps/web/components.json packages/web-common/components.json
```

`apps/web/src` now holds only `main.tsx` (and `vite-env` typings if present).

- [ ] **Step 2: Add the package files**

`packages/web-common/package.json`: `"name": "@fsl/web-common"`, `"private": true`, `"type": "module"`, `"exports": { ".": "./src/index.ts", "./styles.css": "./src/styles/globals.css" }`, scripts `test` (`vitest run`) and `typecheck` (`tsc -p tsconfig.json`). Move **all** runtime `dependencies` of `apps/web` except `vite-plugin-pwa` here (react, react-dom, react-router, @tanstack/react-query, radix-ui, shadcn, tailwind deps, qrcode, sonner, vaul, cmdk, lucide-react, clsx, tailwind-merge, class-variance-authority, tw-animate-css, @fontsource/be-vietnam-pro, @fsl/core) and the test devDependencies (@testing-library/*, @types/*, jsdom if listed).
`tsconfig.json`: copy of today's `apps/web/tsconfig.json` with `"include": ["src", "vitest.config.ts"]` and without `vite-plugin-pwa/client` in `types`.
`vitest.config.ts`: the `test` block from today's `apps/web/vite.config.ts` verbatim (jsdom, `setupFiles: ['./src/test/setup.ts']`, `include: ['src/**/*.test.{ts,tsx}']`, `maxWorkers: 2` with its comment), plus `react()` and the `@` alias to `./src`.

- [ ] **Step 3: `AppRoot` and `bootApp` in `packages/web-common/src/AppRoot.tsx`; `index.ts` re-exports them**

Move the `QueryClient` construction, the provider tree, and the `setLang`/`refetchOnWindowFocus` calls out of `main.tsx` unchanged. The font `@fontsource` CSS imports stay in `apps/web/src/main.tsx`.

- [ ] **Step 4: Update the style guard and make path-based guards fail loudly**

In `style-guard.test.ts`: the "only main.tsx imports CSS" test becomes "no file in web-common imports CSS" (`expect(importers).toEqual([])`), because `main.tsx` now lives in `apps/web`. Add to each path-walking guard (`style-guard`, `ui-components-guard`, `theme`) an assertion that its file list is non-empty, e.g. `expect(code.length).toBeGreaterThan(100)`.

- [ ] **Step 5: Shrink `apps/web`**

`apps/web/src/main.tsx`: font imports, `import '@fsl/web-common/styles.css'`, the service-worker `controllerchange` block (unchanged), `bootApp()`, render `<StrictMode><AppRoot /></StrictMode>`. `apps/web/package.json`: dependencies `@fsl/web-common`, `react`, `react-dom`, `@fontsource/be-vietnam-pro`; devDependencies `vite`, `@vitejs/plugin-react`, `@tailwindcss/vite`, `vite-plugin-pwa`; scripts `dev`, `build` (`tsc -p tsconfig.json && vite build`), `typecheck`; drop `test`. `apps/web/vite.config.ts`: drop the `test` block, keep plugins, PWA, `build`, `server.proxy`; keep the `@` alias but point it at `../../packages/web-common/src` (shadcn files import `@/…`; this is the one sanctioned cross-path, a build alias, not an import). `apps/web/tsconfig.json`: `include: ["src", "vite.config.ts"]`, `paths` `@/*` → `../../packages/web-common/src/*`.

- [ ] **Step 6: Tell Tailwind where the classes are**

Add `@source "..";` right after the `@import "tailwindcss"` line in `packages/web-common/src/styles/globals.css` (path relative to the CSS file → `packages/web-common/src`).

- [ ] **Step 7: Install and run everything**

Run: `npm install && npm run typecheck && npm test -w @fsl/web-common && npm run build -w @fsl/web`
Expected: all pass; test count equals the pre-move count (record it first with `npm test -w @fsl/web` on `main`).

- [ ] **Step 8: Check the build output**

Run: `ls apps/api/public apps/api/public/og apps/api/public/brand && grep -c "fsl-screen__header" apps/api/public/assets/*.css`
Expected: `sw.js`, `manifest.webmanifest`, `index.html`, `og/`, `brand/` present; the grep finds ≥1 match (proves `@source` works) — compare the CSS file size with a build from `main` (within a few %).

- [ ] **Step 9: Commit**

```bash
git add -A packages/web-common apps/web package-lock.json
git commit -m "refactor(web): move the shared app into @fsl/web-common"
```
